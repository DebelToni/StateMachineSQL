# State Machine in PostgreSQL, with python visualization frontend

> Project structure:
Backend - Python flask server connects to PostgreSQL database and serves the data to the frontend.
Frontend - Notepad
Database - PostgreSQL database with the state machine data.

The machine is compact yet extremely powerful—when connected with notifications, it can remain in the same state even on opposite sides of the globe. Perfect for visualization and analysis of staff and processes.
